03 / HOW OUR AI WORKS

Deterministic controls first.
LLM advice second.

The existing Address AI panel and our locally verified Payment Investigation Agent teach two different evidence-grounded AI patterns.

EXISTING WEBSITE

Address Intelligence AI

  1. Parse synthetic MT103 or pacs.008 in the browser.
  2. Run deterministic address-quality checks.
  3. Propose only repairs supported by existing address text.
  4. Ask Gemini for optional explanation via the existing protected backend.
  5. Show before/after; no change is automatically applied.

Not an official CBPR+ validation engine. Human review remains required.

Open existing Address AI ↗
LOCAL AGENT / VERIFIED

Payment Investigation AI

  1. Retrieve synthetic status and event history using read-only Quarkus APIs.
  2. Verify payment ID, provenance and final-event consistency.
  3. Ask Gemini for a constrained JSON explanation when enabled.
  4. Reject unsupported claims and use deterministic fallback.
  5. Return human-review-required result and evidence reference.

Local PAY-10001 Gemini advisory has worked; no public investigation API is deployed.
