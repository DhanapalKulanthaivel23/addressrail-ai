THE BIG PICTURE

Life of a payment.

This is an abstract learning sequence. Real systems may use different networks, controls, messages and settlement models.

1 · InitiationCustomer instructs bank or PSP
2 · ValidationAuthorisation, account and data checks
3 · ExchangeInterbank message or file via selected system
4 · SettlementInterbank obligations settled under system-specific arrangements
5 · ReconciliationConfirm actual processing and customer posting

Important distinction: Sending a message, clearing an instruction, settling a bank obligation, and crediting the beneficiary are different events. A system response can be pending, rejected or unknown.
